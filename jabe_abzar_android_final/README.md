# جعبه‌ابزار Android 1.0.0 — نسخه نهایی پروژه

یک اپ فارسی RTL، ساده و خودمونی با رابط اصلی و ابزارهای کاربردی. این نسخه پروژه Android Studio است.

## نکات مهم
- compileSdk/targetSdk: 36
- minSdk: 23
- QR استاندارد با ZXing
- WebView با file chooser چندانتخابی
- اشتراک‌گذاری متن از طریق Android
- رابط فارسی و RTL
- ابزارهای ماشین‌حساب، تبدیل واحد، تخفیف، یادداشت، تایمر، تاریخ، استودیو عکس، آماده‌سازی سند، PDF UI، QR، متن، JSON، رمز، رنگ، حمل‌ونقل و پیشنهاد کاربران

## ساخت
پروژه را در Android Studio باز کن و Gradle Sync سپس Build > Generate Signed App Bundle / APK را بزن.
برای انتشار Google Play، AAB امضاشده تولید کن.
